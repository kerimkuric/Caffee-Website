How this will work

Milestone 3 adds a PHP service that calls OpenWeatherMap with a timeout. The API key stays in backend/config/config.php (not on GitHub).

  • Backend endpoint, for example GET /weather, returns temperature and a drink suggestion.
  • The home page and this page show a short card, not raw JSON.
  • If the API fails, we log the error and keep the rest of the shop working with a friendly message.
